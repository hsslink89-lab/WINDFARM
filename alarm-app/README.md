# U93 알람 노트 (UNISON U93 2MW 알람 조회 앱)

휴대폰 브라우저용 단일 페이지 앱입니다. 알람코드를 입력하면 다음을 한 화면에서 봅니다.

- **의미**: 발생 조건(원문), 한글 설명, 정지 시 Brake/Yaw 동작, Reset 방식, 반복 알람 조건
- **조치**: 현장 등록 조치(표준조치 지정 가능), 과거 조치 빈도, 매뉴얼 절차, 일반 점검 순서
- **이력**: 일일운전보고 기반 과거 조치이력 (호기별 필터)
- **도면**: 점검 위치 개념도 + 직접 올린 실제 도면/사진
- **+ 조치 등록**: 새로 찾은 해결법을 기록 → 같은 코드 조회 시 맨 위에 표시

## 데이터는 이 저장소에 없습니다

이 저장소는 **공개(public)** 입니다. 알람리스트(사내 Confidential)와 일일운전보고(작업자 실명 포함)
추출본은 커밋하지 않습니다. `alarm-app/data/` 는 `.gitignore` 처리되어 있습니다.

앱이 읽는 파일:

| 파일 | 내용 |
|---|---|
| `data/alarms.json` | 알람 배열: `code, level, category, type, page, name, condition, brake, yaw, reset, repeat, desc_ko, src, tsm?` |
| `data/history.json` | 이력 배열: `d`(일자) `w`(호기) `c`(코드 배열) `e`(에러명) `p`(부품) `a`(조치) `m`(작업자) `h`(MH) `s`(출처 번호) |
| `data/sources.json` | 이력 출처 파일명 배열 |

## 실행 방식

- **claude.ai 아티팩트(비공개)**: 데이터 포함본이 게시되어 있고, 등록 조치·도면은 공유 저장소에 저장됩니다.
- **로컬/사내 웹서버**: `data/` 폴더를 옆에 두고 정적 서버로 열면 됩니다. 이때 등록 조치는 해당 기기 브라우저에만 저장되며,
  "등록된 조치 → 백업"으로 보관하세요.
